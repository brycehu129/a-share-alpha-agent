# GitHub 行情连通性测试

将这两个文件按原路径提交到选定仓库的默认分支：

- `server/collect_quotes.py`
- `.github/workflows/quote-smoke-test.yml`

在仓库的 Actions 页面选择「A股行情连接测试」，点击 Run workflow。
首次提交工作流到 master 分支时也会自动触发；后续只有该工作流文件改动才会触发 push 测试。
如果组织禁用了 Actions 或第三方 Actions，需要由仓库管理员允许这些操作。
本测试不需要行情账号、API key、SSH 密码或新增 secrets。

测试请求上证指数 `sh000001` 和平安银行 `sz000001`，间隔10秒请求，共3次。
成功标准为3次成功请求和6条行情快照；休市期间价格可能不变。
程序打印的行情时间是数据源携带的时间，采集时间是程序实际获取的时间，两者分开保存。
旧行情会提示，不用于宣称市场开市或实时信号。

数据库及日志保存到该次 Actions 运行的 Artifacts，保留7天（受仓库上限约束）。
失败时也尽量上传已生成的日志与数据库，请打开失败步骤或下载 Artifacts 排查。

这是独立的一次性连通性测试：每次工作流新建测试数据库，不恢复上次的数据。
Artifacts 不作为长期预测数据库。本测试不启用定时任务、不产生交易、不更新 Dashboard。
后续接通长期持久化后，再配置日常采集与报告。
